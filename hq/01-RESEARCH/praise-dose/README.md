# Praise dose — is there a nudge regime between silence and command?

**State:** active
**Started:** 2026-08-10

## Abstract

The menu gate (episode 0080) measured praise at the shipped operating
point β = 0.5 as a *command*: selection monoculture 24/24, because the
label's +0.5 dwarfs the drive's whole terminal-value scale (0.06–0.15
in the registered traces). Between β = 0 (praise ignored, rotation
24/24) and β = 0.5 (praise absolute) the curve is unmeasured. A parent
— or a future teacher layer — needs a *preference*: the praised recipe
favored, the menu still alive, the child's own chains intact. Whether
the shipped additive label can express that at any dose is this
topic's question; if it cannot, the label's *shape* is wrong for
nudging, which is a Doc 0010 design finding.

## The question

At doses comparable to the drive's own value scale, does the shipped
`RecipePolicy` label produce a preference (praised recipe favored,
rotation preserved, chains intact) — or is the cliff between silence
and monoculture unbroken at ten-recipe scale?

## Instrument (frozen with the bars)

Identical to the graduated recipe-choice instrument (episode 0080),
reused unchanged: the mc-graduates 24-seed cohort (33-dim, EP 26),
the ten captured tapes, the position-gated judge's label on R5
(wall-center), the shipped `RecipePolicy` with the logged selection
trace, H = 5,000, attribution ±1 step, modal = strict unique argmax.
Measured anchors already on file: β = 0 (modal 0/24, rotation 24/24,
chains 23/24) and β = 0.5 (share 1.00 ×24, chains 18/24).

**The dose grid, frozen:** β ∈ {0.02, 0.05, 0.1, 0.2} — spanning
below, inside, and above the drive's 0.06–0.15 terminal-value range.

**Protocol:** pilot seeds 1–8 at all four doses, published; then the
24-seed confirmatory at the smallest pilot dose that shows the nudge
pattern (or, if none does, at β = 0.02 to pin the cliff's floor at
power). Grid amendments only openly, with the pilot's raw numbers.

## Pre-registered bars

- **Bar D1 — a nudge regime exists:** at some grid β, confirmed at
  24 seeds: praised recipe modal for **≥ 14/24** seeds AND
  monoculture (praised share ≥ 0.8) for **≤ 6/24** AND chains
  **≥ 20/24**. PASS if any dose clears all three together; FAIL is
  the decisive finding that the additive label cannot whisper.

Registered readings (evidence, not bars): praised-share, modal-count,
chains, dwell, switch-rate and entropy as functions of β — the dose
curve itself, including where the cliff sits.

## Reversal condition

This topic assumes the additive label (`value += β·terminal[label]`)
can be dosed into a preference. If even β = 0.02 — a third of the
drive's value floor — produces monoculture in ≥ 18/24 seeds, that
premise is refuted: the label's shape (additive, scale-blind) is the
wrong instrument for nudging, and a drive-relative or multiplicative
label becomes the named successor at Doc 0010's selection seam.

## Verdict

**Bar D1 PASS at ceiling [measured, 2026-08-10, 24 seeds at β = 0.02]**
— the nudge regime exists, and it is clean.

- Praised recipe modal **24/24** (bar 14); monoculture **0/24**
  (bar ≤ 6); chains **24/24** (bar 20 — one better than the β = 0
  menu's 23/24). Praised-share median 0.49; dwell median 89.3%;
  switch median 0.037 `[measured]`.
- The dose curve (pilot, 8 seeds/dose): share 0.49 → 0.69 → 0.88 →
  1.00 across β 0.02 / 0.05 / 0.1 / 0.2; monoculture 0 → 1 → 8 → 8
  of 8. **The cliff sits between 0.05 and 0.1 — where the label
  crosses the drive's terminal-value band (0.06–0.15)** `[measured]`;
  the scale explanation is the same arithmetic measured in episode
  0080 `[mechanism-argument]`.
- Reversal condition unfired: the additive label CAN whisper — β
  comparable to a third of the drive's value floor produces a
  preference, not a command.

Operating points of record: **β = 0.02 nudges** (favorite, menu
alive, chains intact), **β = 0.5 commands** (monoculture, chains
taxed). Doc 0010 carries both.
