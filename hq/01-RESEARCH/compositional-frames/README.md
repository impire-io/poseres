# Compositional frames — what does a reference between frames carry?

**State:** active
**Started:** 2026-08-24

## Abstract

Episode 0116 measured the sequence wall as representational — the frames
hold no deep sequential state — and episode 0117 shaped the gate that
answers it: the primitive to research is **a reference between frames** (a
frame able to point at another and use it as a constituent), with
hierarchy an emergent special case, never an imposed architecture. The
owner's own framing left one core honestly open: what a reference
*carries* — the referenced frame's pose, its prediction, a learned binding
weight, or something else — is unknown, and that is this topic. A decisive
answer either hands the kernel its composition primitive (and re-opens the
sequence envelope ladders 0116 closed), or reverts the gate to
hierarchy-as-built on parsimony, with the tower's numbers on the record.

## The question

What must a reference between frames carry for a frame web to beat a
plain deeper/stacked-frame tower on the frozen echo-teacher world —
same budget, same meters, the 0116 protocol — and is the lifecycle price
(eviction with references live) payable?

## Pre-registered bars

Protocol common to every bar: the frozen echo-teacher world (0115's
frozen `seq.py`), 24 seeds, encodings pinned at 0115's measured leaders,
the ablated-itch policy configuration (itch on the world's own progress
channel, commitment OFF — 0116's licensed configuration), the same step
budget as 0116's arms, graded conformity against exact floors/ceilings
(design 0020's meter guidance). One variable at a time: the frame
mechanism is the only thing that changes between arms.

- **Bar T0 — the tower is real, not assumed.** Before any reference arm
  runs, the plain deeper/stacked-frame baseline — 0117's named parsimony
  rival — runs under the common protocol and its full meter set
  (acceptance and conformity at R(2), R(4), R(8); C(2), C(4)) is
  recorded, whatever the numbers are. PASS = the tower's numbers are on
  the record before any reference arm exists to be compared against
  them. FAIL = any reference arm measured first.
- **Bar R0 — references beat the tower where the wall lives.** At least
  one reference variant beats the tower at R(4) acceptance (higher mean
  across the 24 seeds, and more seeds accepting) without losing inside
  the envelope (R(2) acceptance not below the tower's beyond seed
  spread). FAIL = 0117's reversal fires: the simpler tower wins on
  parsimony and the gate reverts to hierarchy-as-built.
- **Bar W0 — the carried content is answered by measurement, not
  taste.** At least two carried-content variants from 0117's candidate
  list (pose, prediction, learned binding weight) run head-to-head under
  the identical protocol, and the verdict names a leader — or a measured
  equivalence — on the same meters. Measured equivalence is a PASS (the
  answer is "it doesn't matter at this scale," recorded as such); only
  an unrun comparison fails this bar.
- **Bar L0 — the lifecycle is payable.** Under a matched forced-eviction
  protocol (the same eviction pressure applied to both arms, at a
  registered mid-run point), the reference arm's recovery — return to
  its own pre-eviction acceptance band within the remaining budget — is
  not worse than the flat arm's beyond seed spread. FAIL = the primitive
  is re-scoped with those numbers, per 0117.
- **Bar R1 — the frozen line (aspirational, separately reported).** The
  winning reference configuration clears the frozen 2.0 acceptance line
  at R(4) that stood unmet in 0116 (Bar E1) — the line whose clearance
  0116's reversal condition names as overturning the wall's attribution
  and re-opening the envelope ladders. R1 can FAIL while R0 passes; the
  two verdicts are reported separately so "mechanism right, dose
  insufficient" is never conflated with "mechanism wrong."

## Reversal condition

If no reference mechanism beats the plain deeper/stacked-frame tower on
the frozen echo-teacher world at equal budget (R0 FAIL), the tower wins
on parsimony and the gate reverts to hierarchy-as-built — 0117's own
reversal, carried here unamended. If lifecycle costs prove unpayable —
eviction with references measurably destabilizes a population where flat
frames stay healthy (L0 FAIL) — the reference primitive is re-scoped
with those numbers rather than abandoned silently. Either way the
verdict lands in the journey with the raw numbers.
