## 2026-08-15 — the instrument is built (both forms, one palate)

The palate lands at the body seam (bridge): a name → price book, EMA
α = 0.25 (0089's constant) toward the felt pay Δfood/20, paid only
when food rises during a held use. Four build decisions, argued here:

- **The trace.** The world's own naming separates the appearance dug
  (`melon`) from the meal eaten (`melon_slice`) — a mouth-only tongue
  could never light the glance. So a meal pays every name the chain
  touched within 600 game ticks: dig completions, drop pickups, and
  the held item. This is 0089's tongue with the reach of the hands —
  still no decree, no classifier; prices only from felt meals.
  Honest cost: coincidental contacts (dirt dug en route) get paid
  too — superstition the EMA washes out, since the true chain is
  paid every meal and the coincidence rarely.
- **Relative worth.** Both forms expose price / best-known-price —
  scale-free (the budget-arb lesson: κ never magic). A naive book
  reads 0 everywhere; the first meal's chain reads 1.0.
- **Fading is toward each sense's own "nothing".** The salience form
  interpolates the glance dist toward OPEN (1.0) and sigs toward
  absent — a multiplicative fade of dist would read "pressed against
  a wall", inverting the geometry. The drops entry fades toward
  all-zeros, which already means absent. Gain g = (1−f) + f·relPrice
  per appearance: sated everything is plain, starving only what the
  tongue prices remains — the owner's flood intuition applied as
  filtering instead of noise.
- **The ablation is a lookup switch, not a second body.**
  `AIM_ABLATE=1` keeps the palate learning but returns naive prices
  — A3's "worth decoupled, palate-on-meals otherwise identical" by
  construction, same widths, same handshake.
