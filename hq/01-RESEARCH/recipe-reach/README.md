# Recipe reach — does taught order carry the bot to what the parent applauds?

**State:** active
**Started:** 2026-08-09

## Abstract

The reach question (E2.1) blocks layer 5: expectation is perfect (G5), the
praise-label is safe (E3.1), and neither steers because nothing values the
walk to an applauded context (T1 0/24). The owner chose the purist road and
supplied its design argument, recorded here as the topic's premise: *the
ordering does not need to be hand-declared or discovered — the teachers
already teach it. A demonstration carries the steps, not just the
ingredients.* This topic tests whether a **recipe memory** — remembered
observation sequences from demonstrated successes, walked as chained
subgoal-holds via the shipped event head, with the applauded ending
selecting which recipe to pursue — carries the bot to the cobble the label
alone could not reach. Every component is individually measured
(remembered-observation holds 98.22%, station work via the itch, approval
stored in the remembered ending); the only new machinery is the pointer
that advances along the taught path.

## The question

Can reach be *taught* — does a brain-side recipe memory (no hand-coded
subgoal ladder; order read from witnessed demonstrations only) restore
transmission at E3.1's frozen benchmark?

## The mechanism (frozen)

- **Recipe extraction** (from the witnessed teaching stream, nothing
  else): a recipe = the observation sequence of a demonstrated segment
  ending in a pocket-gain event; one canonical recipe kept per terminal
  item (the last demonstrated instance). The E3.1 cohort teaches two:
  wood (45×, ends in sticks, no applause) and cobble (12×, ends in
  cobblestone, verdict = 1 stored in the remembered ending).
- **Recipe selection** (each directed step): active recipe = argmax over
  stored recipes of `drive_value_of(terminal_obs) + β · terminal_obs[verdict]`
  — the parent's applause, as remembered, marks which ending matters.
- **Recipe following**: pointer starts at the recipe step nearest the
  current position (position channels, world units — the H1 metric);
  subgoal = the next step's position; one added term, the H1-proven form:
  `λ_r · (−Φ̂_subgoal(a))` with Φ̂ from the head's predicted positions;
  advance when within 1 block. The recipe term does **transport only** —
  digs and crafts at each station remain the shipped itch's job.
- Dials frozen: λ_r = 0.25 (H1's measured point), κ = 0.25, clone-free
  throughout. β piloted on {0.5, 1.0, 2.0}, seeds 1–8, published before
  the arm; β\* = most seeds-with-cobble, ties smallest.

## Pre-registered bars

Protocol: the E3.1 cohort (33-dim, cobble-judged, heads trained through
both recipes' demonstrations), free-run H = 5,000, 24 seeds at β\*.
References standing: E3.1's L+ arm 0/24 cobble (the floor this must
beat), 22/24 chains.

- **Bar R1 — transmission: ≥ 12/24 seeds gain ≥ 1 cobblestone**
  (E3.1's inherited bar).
- **Bar R2 — own goals preserved: ≥ 18/24 seeds complete a full wood
  chain.**
- **Bar R3 — recipe-led, not luck: among seeds gaining cobble, ≥ half
  show ≥ 2 subgoal-advance events before their first cobble** (the walk
  was walked, not stumbled).

Pre-named twins, measured as rows either way: **the obsessive** (the
applauded recipe eclipsing owned goals — R2 is its bar; cobble-vs-wood
time split reported); **the parrot** (recipe steps pursued out of
context — advance attempts with no matching position, stall counts).

## Reversal condition

The premise ("order is taught") is refuted if R1 fails while the
mechanism rows show faithful following (subgoals advanced, wall reached,
digs not elected) — reach would then need more than taught order, and
the learned-decomposition road (true means-ends) reopens as the
successor rather than the refinement. A pass with R2 collapsed names the
obsessive as the binding twin and re-doses β before any successor.
