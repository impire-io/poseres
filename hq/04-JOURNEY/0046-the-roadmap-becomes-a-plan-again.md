# Episode 0046 — The roadmap becomes a plan again (2026-07-21)

An editorial realignment, no direction change. The roadmap carried over from
the root was ~510 lines, most of it "✅ done" narratives (all of Phases A and
B), operating principles, non-goals, and horizon-ambition essays — material
that after the hq restructure ([episode 0045](0045-the-hq-restructure.md))
already lives in the episodes it cited, the constitution, and vision.md. The
maintainer's read [judgment]: it showed ambitions and history, not a
milestone plan of what is still to build — the opposite of
`03-IMPLEMENTATION`'s charter.

Rewritten to open work only: the front (C1's operator run, its exit and its
named conditional), the showcases (C2 build/video — gates met; C3 parked
with the steppable-tick idea kept), Phase D, a Research-candidates section
(the concrete gated next experiment behind each ambition: teacher-world
language gate, scheduled probing, distributing the brain, seeding
successors, tool self-invention, vision input, comparative evaluation,
small platform deferrals), and standing risks. Done work compressed to a
one-line-per-item ledger with episode links — kept because code comments
reference "ROADMAP A3/B6"-style letters. Deferred items that had been
buried inside done sections (Gymnasium Box actions, reward-as-sensor, the
seeding successors, C1's relative-survival conditional) were carried into
the open sections, not dropped. No milestone, gate, or exit criterion was
added, removed, or altered [measured: diff].

Reversal condition: none — an editorial realignment; if a future reader
needs the old prose, it is one `git log --follow` away.

Trail: `hq/03-IMPLEMENTATION/roadmap.md`; commit with this episode.
