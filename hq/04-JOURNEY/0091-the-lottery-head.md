# Episode 0091 — The lottery head: the first licensed machinery fails its bar honestly (2026-08-11)

Episode 0090 licensed the arc's first new machinery by numbers, and
the owner called the build ("build the richer predictor gate"). The
design followed the measured failure exactly: the trade's outcome is
an *interaction* — zero everywhere except at the trader, where it
falls with the rate — so the minimal generic extension was the
**quadratic event head**: the identical per-action NLMS rule, one
dial, zero RNG, over `[obs, 1, all pairwise products]` (153
features), substituted at the `predict_event_delta` seam with the
shipped arithmetic untouched, pre-trained by deterministic replay of
the cohort's own 48 lessons (the replayed price book equals the
saved book, asserted per seed — the pretraining provably *is* the
witnessed experience).

At 24-seed power the gate **failed its headline bar** [measured]:
ruinous trades 27.8% against the 10% line — statistically unchanged
from the linear anchor — while the bargain lean improved (median
rate 6 vs 7) and nothing else regressed (24/24 life; 20/24 reactive
pacing). And the per-seed distribution, not the aggregate, is the
scientific content: **ruinous shares span 0.00 to 1.00** — six
seeds achieved *perfect* refusal, seven met the bar individually,
four inverted to majority-ruinous — same world, same lessons, same
features, different online trajectories. The quadratic
representation provably carries refusal; getting each brain's head
*to* it online is a lottery.

The pre-registered reversal did not fire: sharpness (sign agreement
on trade outcomes) medianed 0.874 against the 0.90 line that would
have moved blame to value arbitration. So the diagnosis lands with
precision the linear failure never had: not representation (six
existence proofs), not arbitration (the completion rule used sharp
predictions correctly where they existed) — **convergence**. Online
NLMS at η = 0.5 over 153 correlated product features does not
reliably find the interaction each seed needs.

The 0090 license stands unexpended; the next registration has three
named regimes to choose from: **consolidation** (the offline
learning loop Doc 0004 has always reserved — replaying witnessed
trades between waking stretches, which is also the biologically
resonant answer), feature normalization with a lower head η, or
targeted low-order context terms. For the record, plainly: this is
the arc's first gate to fail its headline bar since G1L — and like
G1L, it converted a failure into a mechanism isolation one
experiment sharper than the success would have been.

Reversal condition: none — records a completed measurement whose
named successor is a training regime, not a doubt. If a future
consolidated head passes refusal, this episode is its baseline; if
it too fails at verified convergence, arbitration re-enters with
the sharpness instrument already built.
