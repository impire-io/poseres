# Episode 0067 — PRA goes fair-code (2026-08-08)

An impire-wide licensing decision lands here too: PRA moves from MIT to
the **Sustainable Use License** (n8n's fair-code license, v1.0). Use,
modify, and self-host freely for internal or non-commercial purposes;
offering PRA to others as a paid product or service now requires an
agreement. Public explanation:
[impire.io/license](https://impire.io/license/).

- `LICENSE` replaced with SUL v1.0 (provenance preamble kept), README
  gains a License section, CHANGELOG carries the change under
  Unreleased.
- **Everything published up to and including v1.1.0 stays MIT** — a
  granted license is irrevocable; the new terms start with the next
  release.
- The hobbyists-and-makers bet is unchanged: the free lane (laptop,
  MIT-grade freedom for personal experiments) is exactly the audience
  the vision names. What closes is the unpaid commercial-hosting lane.
- Sole authorship verified (`git shortlog -sne`: one author) before the
  change, so no third-party consent was needed.

Reversal condition: if the license measurably suppresses the
maker/hobbyist adoption the project exists for, MIT returns — the
ecosystem-wide reasoning (and its own reversal terms) lives in
soul-hq journey 0065.
